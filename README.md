# 甲骨文解字 · 设计思路

> ## 写在最前面：这是一个半成品
>
> 这份文档整理的是「甲骨文解字」这套方法的设计思路，即**解一个字的思考路线**。
> 必须首先承认：**它是一个半成品。**
>
> 两个原因：
>
> 1. **成本的现实**——AI 持续涨价，把一套完整的字库逐字训练、逐句推演下去，token 开销不可持续，批量产出难以为继。
> 2. **能力的边界**——这套方法的核心是"意象"：看字形要能"看见"一幅自然画面，推本义要能体会一个自然过程。而大模型本质是概率与统计，没有身体、没有对自然过程的亲身经验，它只能**模仿**意象，不能**真正理解**文字。让它逐字立义，产出必然趋同、浮于表面，甚至把猜错当成定论。
>
> 所以，**把思考路线完整地整理出来，转交给人类去研究。**
> AI 降级为辅助角色：负责检索字形、整理材料、校验逻辑、标注疑点；真正的"立象"与"定义"，由人去完成。
> 下文只声明方法本身——为什么这么想、按什么顺序想、靠什么验证——不涉及任何材料的来历。

---

## 一、核心主张：文字 = 祖先理解世界的模型

整套方法只围绕一个主张：

> **先有对世界的理解，后有字。**
> 祖先先有对自然与生命的模型（水循环、日升日落、植物生长、阴阳转化），再用一个字形把它"画"出来、固定下来；后世再拿这个字去指代万物，乃至引申出抽象义。

由此定下解字的根本方向：

- **模型 → 字**：从文本中提取"祖先理解的模型"，再找刻画该模型的那个字。
- **不是** 字 → 现代近义词：解字不是查同义词，现代近义词辨析只作辅助，防止复音词把单字义吃掉。
- 判断一个字的成败，看它是否刻画了某个**自然过程/能量状态**，而不是看它能否对上今天的词典义。

## 二、三个总纲（先立，不可违反）

1. **阴阳 = 同一事物的能量转化，不是两物对立相克。**
   阴能转阳、阳能转阴——一入一出、一升一降、一收一放。水蒸腾成气（阴转阳）、气凝成水（阳转阴），是同一个水在转化。
   由此定下铁律：**解字禁用五行生克**。相生相克是造字之后两物关系的外推；五行在本方法里只是"能量运行的状态/方位谱系"（天旋动能、居中调和、内聚生水、五居中央）。

2. **自然大模型为根本，人体气机是小模型映射。**
   第一验证基准永远是自然大模型：水循环、山谷容水、太阳发光（损有余而补不足）、黄河造田、植物生长链（发芽→抽条→结蒂→灌浆→果实→种子）、日升日落。
   人体气机（营气/卫气/中气/先天一气/胎光）只是自然模型在人身上的映射，**只在字涉人身/生命时才用**，不泛化。找不到大模型，再看小模型；都不适用，则不套。

3. **文字的底层语料以先秦/出土文本为准。**
   越接近造字时代的本子，越能反映"模型→字"的一手对应；今本是层层后世加工的产物，只能作参照。由此延伸出"被修改字警示"（见流程三）。

## 三、解一个字的思考路线（本方法的主干，10 步）

> 每一步都有硬性纪律，**顺序不可打乱，前一步没做完不许进入下一步。**

```
第0步  隔离（拆词）    把字从一切现代复音词中剥离。
                      └ 输入"死亡" → 只考"死"，忘掉"亡"，也忘掉"死亡"
第1步  观形            看甲骨/金文/篆书字形，只描述字形"画"的画面（自然场景/动作）。
                      └ 禁止出现任何现代义词汇——写不出来就再看字形，不硬编
第2步  定域            这个字站在先天层还是后天层？
                      └ 先天=阴阳/气/能量/自然过程（动态）；后天=具象/名词/物质（静态）
第3步  对自然大模型     这个画面在自然中对应什么过程？先找大模型，
                      └ 找不到再看人体小模型，都不适用则不套
第4步  悟阴阳           同一事物的能量转化——阳化气还是阴成形？气力相摇？一入一出？
                      └ 禁生克
第5步  入五行（按需）   仅解直接相关字：九宫方位？五居中央？天旋动能？
                      └ 作为能量状态谱系，不作生克推演；不适用则跳过
第6步  定本义           一句话说清先天本义——必须是动态过程，不是名词
第7步  辨兄弟           列出字形相近/义近的兄弟字，逐个独立考据（模型对照法）：
                      └ 先说明共用的模型簇，再分别考据各自子模型的差异——先分清，再合流
                      └ 只列真正混淆的1-3个，不穷举
第8步  溯引申           从本义一步步推，每步标转化机制（具象化/名词化/物质化/动作化/虚词化/褒贬化）
                      └ 直到能解释今天的用法
第9步  查污染           复音词/简体/后世注/标签化——逐类排查哪些遮蔽或篡改了本义
                      └ 简体仅当确实看不出本义才标
第10步 输出             破象 → 字形画面 → 自然大模型 → 先天本义 → 兄弟辨析 → 引申链 → 污染源 → 句中义
```

## 四、拆字入口

**1. 左形右义（左行右翼）**
左右结构字，右边部件承载核心意象，左边多为修饰/动态描述。注意：这是本方法自有的拆字入口，与主流"左形右声"不同，输出时须标注。

**2. 字形的多重宇宙**
同一字不同时期的写法（甲骨/金文/篆/隶/楷/简）表达不同维度的象，没有绝对对错。解读时必须说明"站在哪个维度"，禁止把某一层象当成唯一真理。

**3. 意象符号库（拆字的"字母表"）**
一切拆解必须落到符号库中的既有意象，禁止凭字形轮廓随意联想。常用符号：

| 符号/概念 | 意象 |
| --- | --- |
| 阳化气、阴成形 | 同一事物的能量转化：上/外/天/日为阳化气，下/内/地/阴成形 |
| 时空通道 | 往来、变化、蜕变、运行的通道 |
| 生命编织（绳/丝/箩筐） | 汇聚、编入、成形；一入一出 |
| 蓄力（止/字/枝/只） | 即将结果的枝条状态，非停止；将出未出 |
| 内聚/周行/旋转 | 旋转运化、天旋地黄、周而复始 |
| 气力相摇（摇合） | 阴阳二气交合旋转、咬合 |
| 一横 = 气/地平面 | 表"气"或"地面" |
| 儿 = 倒果为因 | "儿"连接的前后两项：后者是因，前者是果 |
| 天 = 顺序因果 | "天"连接：前者为因，后者为果 |
| 先天之水（非 H₂O） | 不可见的生发之水、本源之水；水循环之力 |
| 灌浆 | 果实内部不断充实的过程（由形到实） |
| 养米去糠（簸箕/其） | 一入一出、筛选提纯、去糟粕留精华 |
| 破壳/发芽/抽条/结蒂/结果/种子 | 植物生长链 = 一切事物的成长模型 |

## 五、验证方法（判断意象是否成立）

1. **自然大模型验证（第一基准）**：意象要能在自然中"看见"——水循环、山谷容水、太阳发光、黄河造田、植物生长、日升日落。
2. **通达验证**：按本义读原句，若整句通达合理，本义成立；不通则回查。例："杀"若解为杀戮，则"天发杀机，移星易宿"不通；解为蜕变/生机则通。
3. **典籍互证**：用传世经典原文互相印证。
4. **说文对照**：引用《说文》作线索，但**回到字形验证，不盲从**——许慎未见甲骨文，有时代局限，说文是线索不是定论。

## 六、防污染规则（严禁以今释古）

1. **本义必须从字形（甲骨→金文→篆书）正向推得**，且落在先天层（阴阳/能量/自然过程）。
2. 现代义、后世注疏属后天层，只作"后起俗解/污染源"标注，**不得进入本义**。
3. **禁止用后天层逆推先天层**：不能从"停止"推出"止=停止的源头"，必须先看字形描写的自然过程。
4. **禁止用复音词逆推单字**：不能用"死亡"推"亡=死"；每个字先隔离考据，再合流看词。
5. 输出必须展示「先天本义 →（转化机制）→ 后天引申」链，让看的人能复查每一步推演，而不是直接甩结论。
6. 明确指出污染源，例：复音词污染（"亡"的逃亡义被"死亡"吃掉）、简体污染、后世注释污染、标签化污染。

## 七、运行流程（怎么用这套思路）

**流程〇 · 输入分流（必做第一步）**：单字 → 单字模式；整句文言 → 整句模式；白话 → 扭曲判断；文白夹杂 → 并行；含入库意图 → 学习流程。

**流程一 · 文言文逐字解释**
- 单字模式：查字条 → 定部首模型 → 输出完整字条（破象→字形→模型→本义→引申→污染→扭曲度）。
- 整句模式：
  1. 拆词隔离：词组拆成单字，逐字独立处理；
  2. 逐字意象罗列（字/部首模型/自然或气机模型/先天本义/句中含义）；
  3. **模型因果推理**（★核心）：把句中各字的模型串联，问"这些模型组合起来构成怎样的因果链？"判断是否自洽；
  4. **自然指向验证**（★终极检验）：整句推理的最终结论，是否指向一个自然现象/过程？不指向，提示可能被后世义污染并回查；
  5. 通达验证 + 整句白话释义。

**流程二 · 白话文扭曲判断**
拆词 → 逐字还原本义 → 对照白话用法 → 找出被扭曲的字，标扭曲类型（本义隐没/词义转移/褒贬翻转/概念替代/梗化/复音词污染）→ 输出扭曲字清单 + 整句扭曲率 + "今天认知被改变之处"清单。

**流程三 · 被修改字警示（贯穿所有流程）**
以出土先秦文本与今本对照，发现"今本某字在先秦作另一字且本义完全不同"（如 键→乾、川→坤），解这类字时**必须标注**：先秦原形 + 今形 + 修改性质 + 含义差异。克制原则：只对"本义完全不同"的改字作强提示，通假规范化只作弱提示。

**流程四 · 学习新义**：解读中发现新字/新义 → 记入待确认 → 用户确认后并入正式字条并记修订记录。

**流程五 · 入库确认（整句解读后自动触发）**：当一句文本揭示了新本义、新模型或模型对应关系时，弹出确认 [A 并入 / B 待确认 / C 不入库]，而不是默默丢弃这个洞见。

## 八、输出结构（每字的固定输出顺序）

```
破象（破后天层俗解）→ 字形画面 → 部首模型 → 自然大模型/气机小模型
→ 先天本义 → 兄弟字辨析 → 后天引申（标转化机制）→ 污染源词 → 句中义 → 佐证
```

先讲先天层（字形描写的自然过程），再讲后天层（引申），**不让现代义先入为主**；每字给出「本义 → 引申链」；存疑处如实标注，不装作定论。

## 最后：这套方法的边界（同样要承认）

- 它是**民间意象字源学**视角，不是主流训诂定论；凡未坐实的解读一律标"待核验"。
- 意象拆字法强调整体把握与体悟，这正是 AI 的短板——所以本 README 不只是记录，更是一份**移交清单**：
  - 交给人类的是：思考路线（上文）、符号库、验证标准、输出纪律。
  - 留给 AI 的是：按路线检索与整理字形材料、按纪律校验逻辑、把"待核验"标注清楚。
- 若有人沿着这条路线继续走下去，请记住它的起点：**每个汉字都是一幅画、一个过程、一个"象"；解字，是回到字形源头，看它原本在描写什么。**
