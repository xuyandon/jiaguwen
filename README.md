# jiaguwen · 甲骨文

> 按博主「花无缺黄酒」的意象拆字法，逐字还原汉字上古本义。
> 输入文言文 → 逐字意象解释 + 模型因果推理 + 自然指向验证；
> 输入白话文 → 对照本义，指出哪些字的本义被扭曲。

---

## 一、这是什么

**jiaguwen（甲骨文）** 是一个汉字字源解析技能，方法论提炼自抖音博主 **@花无缺黄酒** 的合集「漢」解析系列（33 集视频转写）。

核心主张一句话：

> **文字的本质 = 祖先理解世界的模型**——祖先先有对自然/生命的理解（如水循环、日升日落、植物生长、阴阳转化），再用字形把它画出来、固定下来，后世再以这个字指代万物。

现代汉语复音词、简体字、后世注释把许多字的本义遮蔽了（如"死亡"把"亡"的逃亡义吃掉；"乾"在先秦帛书作"键"）。本技能从**出土文献（帛书/楚简/清华简等先秦本）**出发，还原每个字本义，并提示被修改的字。

## 五、运行流程

```
输入 → 流程〇 自动分流
├─ 单个汉字 → 流程一·单字模式（部首模型→本义→引申→污染→扭曲度）
├─ 整句文言 → 流程一·整句模式
│    ① 拆词隔离（复音词拆单字）
│    ② 逐字意象罗列（字/部首模型/自然或气机模型/先天本义/句中含义）
│    ③ 模型因果推理（各字模型串联，检查因果链是否自洽）
│    ④ 自然指向验证（结论是否最终指向一个自然现象/过程）
│    ⑤ 通达验证 + 整句释义
├─ 白话 → 流程二（扭曲字清单 + 扭曲率 + 认知变迁点）
└─ 任意 → 流程三 被修改字警示（键→乾等，遇被修改字必须标注）
       → 流程五 入库确认（发现新模型/新字义 → 弹出 [A并入/B待确认/C不入库]）
```

## 六、核心方法（防污染红线）

1. **文字 = 祖先理解世界的模型**：先立模型（如"水循环"），再找帛书对应字，解字形刻画的模型 → 先天本义 → 后世指代。
2. **先破象后立义**：先列现代俗解，破掉它，再立本义（杀≠杀戮而是蜕变；柔≠柔弱而是生长+尖端）。
3. **隔离优先**：任何复音词必拆（"死亡"→死/亡分别考），禁止用词组义覆盖单字义。
4. **观形禁今**：看甲骨/金文/篆书字形时，禁止出现现代义词汇。
5. **以自然现象为终极验证**：水循环/日升日落/植物生长/黄河造田——意象要能在自然中"看见"。
6. **阴阳 = 同一事物能量转化**（禁生克）：五行是能量状态谱系，不是相生相克迷信。
7. **被修改字必标**：键→乾、川→坤等，遇今形标注先秦原形。
8. **诚实标注**：民间意象字源学，非主流训诂定论；`待核验` 字段如实说明。
